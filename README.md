This is a fairly lean static site generator, which I built for [my website](https://demigirlboss.neocities.org/). It's fairly bespoke to the design of my site, but I thought I'd put it up here if only as an intellectual curiosity. It takes pages written in Markdown, and assembles them into an HTML+CSS website which is then pushed to my Neocities via the CLI tool, as well as using YAML frontmatter to appropriately tag the posts for the site's sidebar feed, and pushing everything to an Atom feed. This is not a particularly robust or extensible or modular codebase — it was assembled in a couple afternoons spanning about a year of developments in the nature of agentic development — and it is very much not intended to be used by or for anyone but me. There are better tools out there if you just need a generic SSG. Nonetheless, it's a tool that works *for me*, and if you think it might also be a tool that works for you, then the codebase is here for you to read through and learn from — or, more likely, point your agent at and go, "Write a Skill for building SSGs."
